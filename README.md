\## Project Overview



ChurnGuard AI is an end-to-end data analytics and machine learning project that predicts which telecom customers are likely to leave (churn), identifies the key drivers behind churn, and recommends a targeted retention strategy.



The project follows the Business Intelligence framework: \*\*Data -> Information -> Insight -> Decision -> Action\*\*.



\## Problem Statement



A telecom company is losing customers every month without understanding who is leaving or why. The goal is to:

1\. Analyze customer data to understand churn patterns

2\. Build a machine learning model to predict churn

3\. Identify the top drivers of churn

4\. Quantify the revenue at risk

5\. Design a retention playbook to save high-value customers



\## Dataset



\*\*Name:\*\* Telco Customer Churn  

\*\*Source:\*\* Kaggle  

\*\*Link:\*\* https://www.kaggle.com/datasets/blastchar/telco-customer-churn  

\*\*Size:\*\* 7,043 rows x 21 columns  

\*\*After cleaning:\*\* 7,032 rows  



The dataset contains customer demographics, account information, services subscribed, charges, and churn status.
